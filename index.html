                    HOW TO PLAY

                    操作・バトル・育成のすべて。

                    1. 操作

                    • 自分の球を マウスドラッグ / タッチスワイプ して逆方向に引っ張るとガイド矢印が伸びます。
                    • 指を離した瞬間に、引いた方向と逆へ 初速 が与えられて射出されます。
                    • 球が動いている間にフィールドを タップ すると タップバースト が発動します（1ショットにつき1回）。
                    • ショットを使い切る前に敵を全滅させればウェーブクリアです。

                    2. バトルシステム

                    • 反射: 壁・障害物・敵に当たると弾性反射します。速度はわずかに減衰し、一定速度を下回ると停止して次のショットに移ります。
                    • 弱点コア: 各敵の中心からオフセットされた半径8pxのコア。命中すると ダメージ3倍 かつ ヒットストップ が発生します。
                    • コンボ: 壁や障害物との隙間で高速ヒットを連ねるとコンボ数が増え、ダメージ倍率が 1.0 + (combo × 0.05) 倍になります（コンボ上限は60＝最大 x4.0）。
                    • 友情コンボ: 移動中の球が味方待機球に触れると即時発動します。追尾弾・十字貫通レーザー・衝撃波の3系統があります。
                    • タップバースト: その場で停止し、半径80pxの大爆発衝撃波で全体ダメージ＋敵弾消去。

                    3. ギミック

                    • 誘爆バレル: 耐久3。3ヒットで周囲に特大範囲ダメージ。
                    • 加速板（アクセルギア）: 通過時に進行方向へ 1.8倍 加速（一定速度以上では加速しません）。コンボ稼ぎの要です。
                    • ワープホール: IN / OUT のペアで瞬間移動。速度ベクトルは維持されます。

                    4. シナジー

                    • 跳弾雷撃（reflect + lightning）: 壁反射のたびに最寄りの敵へ落雷。
                    • 連鎖発火（fire + crit）: クリティカル時に着火させ、撃破時に周囲へ誘爆。
                    • 狂戦士の契約（fire + crit + reflect）: 現在HPを10%消費する代わりに攻撃力+100%、与ダメージの15%を吸収。

                    5. 育成とハクスラ

                    • キャラは全4種（火 / 風 / 水 / 闇）、それぞれ ★3 → ★4 → ★5 の3段階進化。進化で友情コンボが大幅強化されます。
                    • 装備は 武器 / レリック の2スロット。Normal / Rare / Epic / Cursed の4レアリティとランダムOPが抽選されます。
                    • 進行状況は localStorage のキー PIXEL_BUSTER_SAGA_SAVE に自動保存されます。

                    6. ショートカット

                    • Esc: ポーズ / I: 装備 / M: サウンド / H: この画面 / Space: タップバースト
